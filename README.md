# 천안오성고등학교 인공지능 중점학교 홈페이지

천안오성고등학교 인공지능 중점학교를 소개하는 정적 웹사이트입니다.
HTML · CSS · JavaScript(Vanilla)만 사용하며, 프레임워크나 빌드 도구가 없습니다.

| 페이지 | 파일 | 내용 |
|---|---|---|
| 메인 | `index.html` | 배너, 연혁, 교육과정 숫자, 특색활동 바로가기, 대외수상 요약·최근 수상 |
| 학교소개 | `about.html` | 연혁, 인사말, 운영 목적, 운영 방침 |
| 교육과정 | `curriculum.html` | 숫자로 보는 교육과정, AI·SW 과목 편성표 |
| 특색활동 | `activities.html` | AI·코딩 페스티벌, 진로 캠프, 코딩 챌린지, 지속가능발전 AI 융합 프로젝트 |
| 대외수상 | `awards.html` | 수상 현황(숫자), 연도별 수상내역 |

## 실행 방법

파일을 더블클릭(`file://`)하면 메뉴·수상내역이 안 나옵니다. 아래 중 하나로 로컬 서버를 여세요.

- **VS Code Live Preview**: 확장 *Live Preview* 설치 → `index.html` 오른쪽 클릭 → **Show Preview**
- **Python**: 프로젝트 폴더에서 `python -m http.server 8000` → `http://localhost:8000`
- **Node.js**: 프로젝트 폴더에서 `npx serve .` → `http://localhost:3000`

서버 종료는 터미널에서 `Ctrl+C`.

## 내용 고치는 방법

HTML 안에 `<!-- 콘텐츠 입력 영역: ○○ -->` 주석이 있는 곳이 내용을 넣는 자리입니다. 주석에 적힌 규칙을 따라 고치면 됩니다.

### 대외수상 — `data/awards.json`만 고치세요

수상 현황 숫자, 연도 버튼, 수상내역 표, 메인의 최근 수상이 **모두 이 파일에서 자동으로 만들어집니다.** HTML은 고치지 않습니다.

```json
{
  "연도": 2026,
  "대회": "제3회 충남 학생 AI코딩 창의력 한마당",
  "주관": ["충청남도교육청"],
  "분야": "AI 코딩",
  "수상": "금상1, 은상3, 동상3"
}
```

- **키 이름(연도·대회·주관·분야·수상)은 한글 그대로** 두어야 합니다.
- `주관`, `분야`: 하나면 문자열, 여러 개면 `["…", "…"]` 배열. 없으면 `""`.
- `수상`: 쉼표로 구분합니다.
  - `금상3` → 금상 3개 (숫자 = 개수, 숫자가 없으면 1개)
  - `1위`, `2위` → 순위 (각각 1개로 셈)
  - 대상·금상·은상·동상·1~3위는 메달, 우수상·장려상·입상은 리본 아이콘이 붙습니다. 그 밖의 상(예: 총장상)은 아이콘 없이 표시됩니다.
- 같은 연도 안에서는 JSON에 적힌 순서대로 보입니다. 메인의 '최근 수상'은 맨 위(최신 연도의 첫 항목)부터 3건입니다.
- JSON은 쉼표 하나만 틀려도 전체가 안 나옵니다. 고친 뒤 꼭 페이지를 열어 확인하세요.

> **수상 학생 수**는 학생 명단이 없어 `총 수상 수 × 2`로 계산한 **추정치**입니다.
> 배수는 `js/awards-data.js`의 `CONFIG.studentsPerAward`에서 바꿀 수 있습니다.

### 교육과정 — `curriculum.html`

- **편성표**: 학년별로 `<tbody>` 하나입니다. 학년 칸의 `rowspan` 숫자는 그 학년의 과목 수입니다. 1과목이면 생략합니다.
- **숫자 카드**(편성 학점, 과목 수, 비율)는 자동 계산이 아닙니다. 표를 바꾸면 숫자 세 개와 막대의 `style="width: 22.4%"`도 **직접** 고쳐야 합니다.
- 숫자 카드는 메인에도 그대로 표시되므로 `curriculum.html`에서만 고치면 됩니다.

### 연혁 — `about.html`

- 오래된 순서대로 적고, 현재 단계에만 `timeline__item--current` 클래스와 `aria-current="step"`을 붙입니다.
- 메인에도 그대로 표시되므로 `about.html`에서만 고치면 됩니다.

### 특색활동 사진 — `activities.html`

1. 사진을 아래 **사진 규칙**에 맞게 변환해 `images/`에 넣습니다. 원본 사진은 사이트 폴더 밖에 따로 보관합니다.
2. 사진 하나가 `<li>` 하나입니다. 기존 `<li>`를 복사해 `src`, `width`·`height`(사진 파일의 실제 가로·세로 픽셀), `alt`, 캡션을 바꿉니다.
3. `alt`에는 사진에 보이는 장면을 한 문장으로 적습니다. 화면을 보지 못하는 방문자가 듣는 설명입니다.

메인의 특색활동 카드(`index.html`)는 따로 적혀 있으므로, 활동 이름이나 순서를 바꾸면 메인도 함께 고칩니다.

#### 사진 규칙 — 세로 480px · 고품질 JPG 권장

- **크기:** 세로(높이) **480px**로 줄입니다. 가로는 비율대로 따라갑니다 (예: 3:2 사진 → 720×480).
- **형식:** **JPG, 고품질**(품질 90 안팎)로 저장합니다. 이렇게 하면 한 장에 100~200KB 정도로 화면에서는 선명하고 용량은 작습니다.
- **대용량 이미지는 쓰지 않습니다.** 카메라·휴대폰 원본(가로 4000~6000px, 한 장 수 MB~수십 MB)을 그대로 넣으면 화면에 보이는 크기는 같아도 내려받을 양이 수십 배라, 휴대폰에서 페이지가 아주 느리게 열리고 데이터도 많이 씁니다. 원본은 사이트 폴더 밖에 보관하고, 줄인 사진만 `images/`에 넣으세요.
- 변환 후 `activities.html`의 `width`·`height`를 실제 픽셀 크기(예: `width="720" height="480"`)로 맞춥니다.

## 디자인 규칙

- **반응형은 PC / 모바일 2단계뿐**입니다. 브레이크포인트는 `@media (max-width: 768px)` 하나만 쓰고, 모바일 스타일은 `style.css`의 `18. 모바일`에 모아 두었습니다.
- 색·글자 크기·간격은 `style.css` 맨 위 `01. 디자인 변수`(`--color-primary: #172554` 등)를 씁니다. 새 색을 직접 쓰기보다 변수를 쓰세요.
- 글꼴: Pretendard (CDN)
- 클래스 이름: BEM (`블록__요소--변형`, 예: `card__title`, `section--gray`)
- 현재 페이지 메뉴에는 `main.js`가 `active` 클래스를 붙입니다.
- `style.css` 맨 위에 목차가 있습니다. 새 스타일은 해당 번호 구역에 넣습니다.
